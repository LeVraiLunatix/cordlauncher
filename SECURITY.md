# Sécurité

## Signaler une faille

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.

Utilise plutôt le signalement privé de GitHub : onglet **Security › Report a vulnerability** de ce dépôt. Décris ce que tu as trouvé, comment le reproduire et ce qu'un attaquant pourrait en faire.

Tu auras une réponse dès que possible ; une fois la faille corrigée et publiée, tu seras remercié·e (si tu le souhaites) dans les notes de version.

## Ce qui est concerné

- CordLauncher (l'app Windows, son installateur, ses mises à jour) ;
- le service Compte Cord (`account-service/`) et son portail, [compte.cordsuite.app](https://compte.cordsuite.app) ;
- la connexion avec Passcord et les notifications.

Les apps de la suite ont chacune leur dépôt : signale une faille dans Drivecord ou Passcord sur le dépôt concerné.
